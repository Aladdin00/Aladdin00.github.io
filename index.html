Data Professional Survey Dashboard

  • Power BI
  • Excel
Problem
Understand who works in data and how they feel about their careers, using a survey of data professionals.
Approach
Took the survey data from Excel (630 responses) and built a one-page Power BI dashboard with the number of respondents, average age, job titles, favorite programming language, difficulty of breaking into data, satisfaction with salary and work/life balance, and respondents by country.

Nashville Housing Data Cleaning

  • SQL Server
  • T-SQL
Problem
The raw housing data had inconsistent dates, missing addresses, combined address fields, mixed Y/N values and duplicates.
Approach
Standardized the sale date format, filled missing property addresses with a self-join on ParcelID, split addresses into street, city and state with SUBSTRING and PARSENAME, converted Y/N to Yes/No with CASE, found duplicates with a ROW_NUMBER CTE and dropped unused columns.
Result
A clean, consistent table that is ready for analysis.
